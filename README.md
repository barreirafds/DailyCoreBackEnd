## 📖 About the Project

DailyCore is a Full-Stack productivity application developed as an individual university project at Fontys University of Applied Sciences.

The application aims to help users organize their daily routines and tasks through a simple and structured platform.

This repository contains the Back-End implementation.

## ✨ Features

- User registration and authentication
- Routine management
- Task management
- REST API endpoints
- PostgreSQL database integration
- Automated testing

## 🏗️ Architecture

The Back-End follows a layered architecture to separate application responsibilities.

- **Controllers:** Handle HTTP requests and responses.
- **Services:** Implement business logic.
- **Repositories:** Manage database operations.
- **Models/Entities:** Represent application data.

## 🧪 Testing & Quality

The project includes practices focused on software quality:

- Integration testing using MockMvc
- Automated testing with JUnit
- Code quality analysis using SonarQube
- Security assessment using OWASP ZAP
- Automated build and testing workflows

## 🚀 Local Development

Requirements:

- Java 21
- PostgreSQL
- Gradle

Clone the repository:

```bash
git clone https://github.com/barreirafds/DailyCoreBackEnd.git
cd DailyCoreBackEnd
```

Configure the PostgreSQL connection using the application's environment variables or local configuration.

Run the application using the project's Gradle wrapper.

**Note:** Check the repository's configuration files for the exact commands and required environment variables.
